{%- comment -%} Feed card for a `layout: directory` post (see _layouts/directory.html). It keeps an ordinary card's footprint -- same image slot, same grid cell, same featured treatment -- so the 2-column grid keeps its rhythm. What marks it as a directory is the image slot: instead of a photo it holds a miniature of the board the card opens, one column per section with the first few post titles as tiles (dashed while a linked post is unpublished). The body lists the sections with their counts; a featured card also lists a few posts under each.
