{%- comment -%} Glide: the hover for lists (styles: _sass/misc/spotlight.scss). Mouse only. A list marked data-glide="" gets one highlight block (.glide-pill) behind its rows. It fades in on the row under the pointer, then slides from row to row: the edge facing the next row leads and the far edge follows a beat later, so the block briefly stretches. The stretch never reaches more than one row back, and that tail fades out. It fades away when the pointer leaves the list. Lists can nest; each keeps its own block. (Tag chips don't glide: they light up in place, CSS only.) {%- endcomment -%}
