{%- comment -%} Sets has_banner and banner_image: the page's own banner picture -- a post's cover, which fills its page hero (_layouts/post.html) -- from `banner: { image: ... }` or `banner: "..."`. A Notion post with no cover is synced as `banner: { image: "" }`, and Liquid takes "" for true, so an empty one is turned into nil here: no banner. {%- endcomment -%} {%- assign has_banner = false -%} {%- if page.banner.first -%} {%- assign banner_image = page.banner.image -%} {%- else -%} {%- assign banner_image = page.banner -%} {%- endif -%} {%- if banner_image == "" -%}{%- assign banner_image = nil -%}{%- endif -%} {%- if banner_image -%} {%- assign has_banner = true -%} {%- assign banner_image = banner_image | relative_url -%} {%- endif -%}
